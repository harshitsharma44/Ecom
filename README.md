# 🛒 MERN E-Commerce Platform

A full-stack e-commerce web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).

## 🚀 Features
- User Authentication (JWT)
- Product Listing
- Add to Cart
- Order Management
- Responsive UI

## 🛠️ Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB

## 📦 Setup

### Backend
cd backend  
npm install  
npm run dev  

### Frontend
cd frontend  
npm install  
npm start
